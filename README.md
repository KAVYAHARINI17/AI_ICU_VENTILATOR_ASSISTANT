<h1>AI ICU Ventilator Assistant</h1>

<p>
A real-time ICU decision support system for ventilator parameter analysis,
combining machine learning prediction, clinical guideline logic, and explainable AI.
</p>

<p>
Built using <strong>FastAPI</strong> (backend) and <strong>Streamlit</strong> (frontend),
the system predicts tidal volume based on patient vitals, integrates condition-specific
ventilation strategies (ARDS, COPD, restrictive patterns), and provides
<strong>SHAP-based interpretability</strong> for transparent model insights.
</p>

<h2>Key Capabilities</h2>

<ul>
  <li><strong>Tidal Volume (TV)</strong> prediction from physiological parameters</li>
  <li>Weaning readiness evaluation</li>
  <li>Real-time vitals simulation</li>
  <li>Condition-based ventilation recommendations</li>
  <li>Integrated AI assistant for contextual explanations</li>
  <li>Exportable PDF clinical summaries</li>
</ul>
